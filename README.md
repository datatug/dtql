# dtql
DTQL specification — an open YAML-based query language for relational, document, API, and graph-connected data.

The [layered ACL MVP design packet](design/layered-acl/README.md) proposes portable policy and authorization contracts across DTQL, DALgo, InGitDB, OpenVaultDB and DataTug. It includes the current-state audit, implementation work packages and independent review material. Its contracts remain subject to design review and human approval; the MVP is not implemented by this packet.

The [human checkpoint and review report](design/layered-acl/reviews/README.md) includes both independent reviews, separate reconciliation, proposed decisions and measured review cost/value. The implementation plan was reviewed alongside the design; neither is approved for execution yet.
